# Scalpel Economy

PoE 2 in-game economy browser (Runes of Aldur): category filter, search, icons, and a pop-out overlay panel beside the game.

## Install (dev)

From this directory:

```bash
npm install
npm run install:scalpel
```

Or build and copy `dist/` into `%APPDATA%/Scalpel/plugins/scalpel-economy/` (and add `"scalpel-economy"` to `installed.json`).

Requires Scalpel with the plugin SDK (`@scalpelpoe/plugin-sdk` via `file:../../src/plugin-sdk` when developing in-repo).
